---

### High-level architecture

- **Public app (outsiders):**
  - `/` → marketing site + signup
  - `/login` → auth
  - `/dashboard` → customer portal (tiers, services, payments)
- **DivinityVX private hub (you only):**
  - `/divinity` → locked, owner-only index/homepage
  - Full control over:
    - Dispatch decisions
    - CaaS / FaaS / micro‑hubs / customs
    - Pricing tiers
    - Partner onboarding
- **Backend services:**
  - Auth + roles (`OWNER`, `CUSTOMER`, `CARRIER`)
  - Billing (Stripe or similar)
  - Dispatch API
  - Compliance API
  - Fleet API
  - Reverse logistics API

---

### Role-based access model (core idea)

```ts
// auth/roles.ts
export type Role = 'OWNER' | 'CUSTOMER' | 'CARRIER';

export interface User {
  id: string;
  email: string;
  role: Role;
}

export function isOwner(user?: User) {
  return user?.role === 'OWNER';
}
```
